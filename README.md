# Capital Malaya — capitalmalaya.com

Official website of Capital Malaya, founded 27 November 2026.

- `index.html` — public site (shows live company capital only)
- `hq/` — HQ Portal, founders' login
- `config.js` — Supabase connection (publishable key; data protected by Row Level Security)
- `assets/` — logo and icon

Hosted on GitHub Pages. Every commit to `main` goes live in about a minute.
